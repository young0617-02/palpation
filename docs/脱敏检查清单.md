## 1. 目的与范围

本仓库在推送 GitHub 私有仓库前，会先将 git 历史**重建为单一初始提交**。因此旧提交历史不进入远端，历史中的作者信息由历史重建任务单独处理；本清单只针对**最终入库的文件内容**负责。

范围包括：

- 工作区全部文本文件（排除 `.git`、`.venv`、`*.lock` 与二进制文件）；
- `git ls-files` 中被跟踪的文件名；
- `evidence/` 下 7 张 PNG 截图（`S1_quality_gate.png`、`S4_e2e.png`、`S4_e2e_result.png`、`S5_events.png`、`S8_ota.png`、`S9_grafana.png`、`S13_containers.png`）；
- 未跟踪但可能被一并提交的文件（见 D10）。

不在范围：git 历史中的 commit 作者/提交者字段、远端仓库配置、第三方模型资产本体。

> 本清单自身不记录任何被移除的敏感原文；涉及位置时只描述**内容类型**。
